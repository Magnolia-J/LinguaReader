# 导出示例（Export Samples）

本目录用于说明 LinguaReader 知识库「导出词汇」功能支持的**输出格式**。

> 注意：这里的文件是**格式说明占位**，不包含任何真实内容。
> 你在软件里点击「导出」后，会按所选格式生成你自己的知识库文件。

## 支持的格式

| 格式 | 说明 | 典型用途 |
|---|---|---|
| `.md` | Markdown，分「词汇 / 表达 / 句型 / 批注 / 笔记」等分区 | 通用笔记、Obsidian / Notion 导入 |
| `.html` | 带样式的网页 | 浏览器直接查看、打印成 PDF |
| `.docx` | Word 文档 | 交给老师、打印 |
| `.csv` | 表格（每类一张） | Excel / 表格软件、Anki 制卡 |
| `.txt` | 纯文本 | 任意编辑器 |

## 导出时可选项

- **按词典来源筛选**：仅导出某个词典（如 Larousse、Le Robert、CNRTL）的释义。
- **导出模式**：全部释义 / 仅默认词典 / 每词最佳释义。
- **显示原文词形**：保留你阅读时遇到的原始词形（而非词根/Lemma）。

导出内容来自你本机浏览器或本地服务的数据，**不会上传到任何第三方**。
